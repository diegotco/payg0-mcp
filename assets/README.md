`logo.png` (512×512): the Payg0 icon, "g0" in Inter Black (SIL Open Font
License 1.1) in the brand colors (#e2e8f0 g, #6366f1 0) on #080810. It is a
copy of payg0.io's app icon.

It is a PNG on purpose: cursor.directory inverts the colors of SVG logos
(it assumes they are black-on-transparent), which turned this one light.
